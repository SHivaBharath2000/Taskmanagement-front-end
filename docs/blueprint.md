# **App Name**: Nexus Tasks

## Core Features:

- User Authentication: Login and registration pages to connect with the backend API, securely handling access and refresh tokens.
- Responsive Task Dashboard: Display a comprehensive list of tasks retrieved from the backend API in a responsive layout for desktop and mobile.
- Task Filtering and Search: Implement UI features to filter and search the displayed tasks based on various criteria.
- Task Management (CRUD): User interface and forms for creating, reading, updating, and deleting tasks, including toggling their completion status via the backend API.
- Operation Notifications: Display simple toast notifications for successful operations like adding, editing, or deleting tasks.

## Style Guidelines:

- The visual design will adopt a light color scheme, reflecting professionalism and clarity for a productive environment.
- Primary color: A sophisticated, muted blue (#335999) to convey stability and focus in task management.
- Background color: A very light, desaturated blue-gray (#F0F4FA) that provides a calm and unobtrusive canvas for tasks.
- Accent color: A vibrant cyan-like hue (#33B0CD) for calls to action, important statuses, and interactive elements to provide visual emphasis.
- Body and headline font: 'Inter', a grotesque-style sans-serif, chosen for its modern, objective, and highly legible characteristics across all screen sizes.
- Utilize a set of minimalist, vector-based icons that are clearly identifiable for common task actions (e.g., add, edit, delete, complete, search, filter) ensuring visual consistency.
- Implement a responsive, clean, and spacious layout using a card-based structure for task display on larger screens, transitioning to a streamlined list for mobile devices to ensure optimal readability and interaction.
- Subtle and functional animations will be incorporated for state changes (e.g., task completion, filtering), modal transitions, and notification pop-ups to enhance user experience without distraction.
